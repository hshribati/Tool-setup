# Weather Advisor Final Project
## Weather Report Definition

**Course:** ITMO 544 - Cloud Computing

### 1. Report Purpose

The Weather Advisor application helps users plan their day using weather forecasts and AI-generated advice.

Users enter a US ZIP code, select a date, and choose a gender option.

The application provides separate morning and night weather reports.

### 2. Report Time Periods

- Morning: 6:00 AM to 11:59 AM.
- Night: 6:00 PM to 11:59 PM.
- Dates: Today and the next six days.
- Time zone: Based on the selected location.

### 3. Report Fields

Each morning and night report includes:

1. Temperature in Fahrenheit.
2. Wind speed in miles per hour.
3. Visibility in miles.
4. UV Index.
5. Humidity percentage.
6. Rain category.
7. Snow category.
8. Road condition advice.
9. Clothing advice.
10. Accessories advice.

### 4. Weather Data Sources

- Zippopotam.us: ZIP code and location information.
- National Weather Service: Temperature, wind, humidity, rain, snow, and primary visibility data.
- Open-Meteo: UV Index and backup visibility forecasts.

Weather measurements are not generated by AI.

### 5. Weather Calculations and Categories

The application calculates weather values separately for each morning and night period.

- Temperature: Average of available hourly temperatures in Fahrenheit.
- Wind speed: Average of available hourly wind speeds, converted to miles per hour.
- Humidity: Average of available hourly humidity percentages.
- Visibility: Average of available NWS visibility values. Open-Meteo is used as a backup. Values are converted from meters to miles.
- UV Index: Average of available hourly Open-Meteo UV Index values.
- Precipitation probability: Maximum probability during the selected period.

#### Rain and Snow Categories

The application checks NWS forecast descriptions for rain or snow.

When rain or snow is mentioned, the maximum precipitation probability determines the category:

| Probability | Category |
|---|---|
| 70% or higher | Heavy |
| 30% to less than 70% | Mild |
| Below 30% | No |
| Missing probability | Unknown |

These are application-defined probability categories, not measurements of actual precipitation intensity.

If rain or snow is not mentioned in the forecast, the application returns No.

### 6. AI Advice

Google Gemini generates clothing, accessories, and road advice using weather facts.

If Gemini is unavailable, the application uses backup advice rules.

The report identifies the advice source as "gemini" or "fallback".

Road advice is guidance, not a guarantee of safety.

### 7. Missing Data

If a weather field is unavailable, the report displays "Not available".

A UV Index of 0 is a valid value, especially at night.

The application does not invent missing weather measurements.

### 8. Weather Cache

Weather data is stored in Amazon DynamoDB.

- Table: final-weather-cache
- Cache duration: 600 seconds
- Expiration field: expires_at
- DynamoDB TTL: Enabled

The API identifies whether weather information came from live APIs or the cache.

### 9. Report Delivery

Users can view weather advice on the Advisor webpage.

The application also supports email reports using Amazon SNS.

Email subscriptions require confirmation before messages can be delivered.

### 10. Security and Privacy

The Gemini API key is stored as an encrypted SecureString in AWS Systems Manager Parameter Store.

The API key is not included in weather reports.

The application validates user inputs and uses private email subscriptions.

- 37 automated tests passed.
- Visibility and UV Index returned forecast values.
- DynamoDB successfully returned cached weather data.
- Gemini successfully generated morning and night advice.

These results confirm the tested local application behavior. They do not replace full AWS deployment, performance, or security testing.
